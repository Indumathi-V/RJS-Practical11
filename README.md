# React Practical – Conditional Rendering

## Title

Display Welcome Message After Login Using Conditional Rendering

---

## Aim

To implement conditional rendering in React using:

- useState Hook
- Event Handling (`onClick`)
- Conditional Rendering
- Ternary Operator

---

## Problem Statement

Create a React application using Create React App.

Initially, the application should display:

**Login**

When the user clicks the Login button:

- Display the message **Welcome Student**
- Hide the Login button.

The welcome message should be displayed **only after login**.

---

## Requirements

Your application must:

1. Use the `useState` Hook.
2. Maintain a login state.
3. Initially set the login state to `false`.
4. Use an `onClick` event for the Login button.
5. Change the login state when the Login button is clicked.
6. Use a **ternary operator** for conditional rendering.
7. Display `Welcome Student` only when the user is logged in.
